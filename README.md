# Reiseverwaltungstool

WordPress-Plugin für die eigenständige Verwaltung und Darstellung der Reiseangebote von Wagner Reisen.

Die redaktionellen Reisedaten bleiben in WordPress. Für die eigentliche Buchung verweist jedes Angebot direkt auf Busfinder. Dadurch ist die Website weder von Traveler noch von einem bestimmten Theme oder Page-Builder abhängig.

## Plugin

Das installierbare Plugin befindet sich unter [`wagner-reiseangebote`](./wagner-reiseangebote).

Aktueller Funktionsumfang:

- Reiseangebote mit Reisearten und Reisezielen
- Termine, Preise, Status und Zustiegsstellen
- Reiseprogramm mit frei ergänzbaren Programmpunkten
- Leistungen, Beitragsbild und Bildergalerie
- externer Busfinder-Buchungslink
- filterbare Übersicht und responsive Detailseiten
- strukturierte Daten für Suchmaschinen

## Entwicklung

Neue Versionen werden zuerst auf `wagner-admont.at` geprüft. Die produktive Website `wagnerreisen.at` wird erst nach einer gesonderten Freigabe aktualisiert.
